# Licenses

This repository mixes code under kernel-compatible licenses with
documentation under a Creative Commons license. Each file carries an SPDX
identifier; the summary is:

- `patches/`, `dts/` — GPL-2.0, matching the Linux kernel.
- `topology/` — BSD-3-Clause, matching AudioReach.
- `tools/` — GPL-2.0-or-later unless a file states otherwise.
- `README.md`, `STATUS.md`, `AGENTS.md`, this file — CC-BY-4.0.

Full license texts: the GPL-2.0 is in the Linux kernel `COPYING` file; the
BSD-3-Clause and CC-BY-4.0 texts are at https://spdx.org/licenses/ .

No proprietary firmware is included. See README.md.
